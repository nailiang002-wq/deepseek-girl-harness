# DeepSeek 娘 · Harness Desktop

**一个会陪你思考、写答案，也会捧着铁盆等你喂饭的小挂件。**

[English](README.en.md) · 中文 · **v1.3.0** · [下载安装包](https://github.com/nailiang002-wq/deepseek-girl-harness/releases/tag/v1.3.0)

![DeepSeek 娘的十种表情](docs/images/overview.png)

DeepSeek 娘是为 **DeepSeek Harness Desktop** 制作的互动角色插件。她会跟随当前任务改变表情，你也可以把她拎到窗口另一边、喂她一盆白饭，或给她戴上铁盆帽。早晨、午间和夜晚，她会用小气泡跟你打招呼。

角色显示在 Harness 窗口内。安装后即可使用，动画和互动都在本地播放，不需要额外的模型调用。

## 她会做什么

| 功能 | 表现 |
| --- | --- |
| 跟随任务 | 推理时思考，正文输出时认真回答，完成后庆祝，出错时露出委屈表情 |
| 喂一盆白饭 | 点击装着白饭的铁盆，她会开心地舀饭、咀嚼，约 4 秒后回到当前任务状态 |
| 捧盆求饭 | 待机时举着空铁盆等你投喂；吃饱后两分钟内不再求饭 |
| 铁盆帽 | 可以戴上、摘下倒扣的银色铁盆；帽子会和角色一起动 |
| 拎起与落地 | 拖动时轻轻摇晃，松手后播放落地动作，并记住新位置 |
| 时间问候 | 按电脑本地时间打招呼，深夜提醒注意身体和休息 |
| 休息 | 空闲 90 秒后闭眼休息；有鼠标或键盘活动时醒来 |
| 动画控制 | 可预览表情、暂停动画；支持系统减少动态效果设置，窗口隐藏时暂停视觉播放 |

共有 **10 种状态**：待机、思考、回答、完成、错误、拖动、落地、休息、捧盆求饭、开心吃饭。手动停止任务或等待授权不会被当作成功完成。

## 安装

1. 从 [Releases](https://github.com/nailiang002-wq/deepseek-girl-harness/releases/tag/v1.3.0) 下载 `DeepSeekGirl-Harness-v1.3.0.zip` 并解压。
2. 打开 Harness 左侧的 **插件 → 添加插件**。
3. 输入解压后 `DshDeepSeekGirl` 文件夹的完整路径，安装并启用。
4. 按应用提示重新载入界面；如果没有重新载入入口，退出并重新打开 Harness。

也可以直接下载或克隆本仓库，将包含 `package.json` 的仓库根目录作为插件目录添加。**使用已经编译好的插件无需安装 Node.js，也无需执行构建命令。**

已在 Windows 版 DeepSeek Harness Desktop 验证；其他系统尚未实测。插件使用 Harness 的 Cordis 接口，依赖应用内提供的会话和聊天服务。

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住角色拖动 | 移动角色 |
| Ctrl + 滚轮 | 调整大小 |
| 点击或右键角色 | 打开表情与互动菜单 |
| 点击旁边的白饭盆 | 喂饭 |
| 菜单：戴上 / 摘下铁盆帽 | 切换帽子 |
| 菜单：和我打个招呼 | 手动触发当前时段的问候 |
| 菜单：关闭时间问候 / 待机捧盆求饭 | 关闭对应的自动互动 |
| 菜单：暂停动画 | 停止姿势播放和连续摆动 |

位置、大小、帽子和互动开关会保存在本地。插件列表中可关闭或卸载本插件。

## 时间问候

| 本地时间 | 问候 |
| --- | --- |
| 05:00–10:59 | 早上好～今天也一起加油吧！ |
| 11:00–13:59 | 中午好～记得吃午饭，我也想要一盆白饭！ |
| 14:00–17:59 | 下午好～忙了一阵，喝口水休息一下吧。 |
| 18:00–22:59 | 晚上好～辛苦啦，记得放松一下。 |
| 23:00–次日 04:59 | 已经很晚啦～熬夜也要注意身体，记得休息哦。 |

每个时段只自动问候一次，切换会话或重新打开应用不会反复提醒。午夜前后属于同一个深夜时段。工作、吃饭、拖动、预览表情或打开菜单时，问候会等到空闲再显示；气泡约 10 秒后消失，也可以点击 × 关闭。

## 动画与本地运行

v1.3 将逐张切图的计时器改为预先解码的透明图集，由浏览器播放。连续呼吸和摆动不需要每帧刷新整个挂件；拖动按屏幕刷新节奏合并位置更新。角色的手势和表情仍由原来的六个关键姿势组成，并非逐帧重新绘制的人物动画。

插件读取当前会话的任务状态，不改写聊天内容，不发送外部上报，也不会为了喂饭或问候额外调用模型。

## 开发

需要 Node.js 20 或更新版本。所有源图、编译模板和测试都包含在仓库内。

```sh
npm install
npm run build
npm test
```

可选的真实浏览器检查：

```sh
npx playwright install chromium
npm run test:browser
```

`client.template.js` 是客户端模板，`scripts/build.cjs` 将 `assets/frames` 与 `assets/props` 编译成 `client.js`。`logic.js` 负责状态和时间规则，`projection.js` 负责正常完成、错误和停止的区分。测试临时文件写入 `.cache/`。

浏览器检查覆盖十种图集的位置、循环与单次播放、吃饭重播、帽子、暂停、减少动态效果、隐藏窗口和拖动保存。独立测试页面中，循环播放约 3 秒时角色组件的刷新由旧版 10 次降至新版 0 次；这不代表所有机器或应用负载下都能保持固定帧率。

## 关于素材

这是一个非官方角色插件，与 DeepSeek 官方无隶属关系。插画通过 ImageGen 根据项目创建者提供的角色参考生成，生成提示词见 [assets/generation-prompts.txt](assets/generation-prompts.txt)。原始参考图片未包含在仓库中。
