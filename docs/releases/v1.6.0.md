## 中文

小衣柜来了：经典女仆装、蓝白休闲卫衣、星星睡衣，可以先试穿，再决定今天穿哪一套。吃白饭也修好了，现在会连续吃三口。

- 三套衣服各自覆盖全部 12 种状态，共 234 个关键姿势。思考、回答、求饭、吃饭、摸头、鼓脸和拖动都有对应服装。
- 从角色菜单打开小衣柜，点选试穿，按“就穿这套”保存。取消、Escape 或点击衣柜外面，会恢复已经保存的衣服。小窗口可在选中卡片中查看当前动作。
- 喂饭连续播放三次完整的舀饭、抬勺入口和咀嚼，约 13 秒后恢复当前任务。十二个吃饭姿势复用三次，共 36 次姿势播放。
- 换装接着当前动作的进度播放，保留帽子、位置、大小、问候等偏好。衣服保存在本地，下次打开继续穿。
- 图集仍由浏览器播放，解码缓存限制数量，保留暂停、隐藏窗口和减少动态效果；互动无需额外模型调用。

下载 `DeepSeekGirl-Harness-v1.6.0.zip`，解压后在 Harness 添加 `DshDeepSeekGirl` 文件夹。已有用户先备份，再覆盖插件文件，退出并重新打开 Harness；从角色菜单选择“打开小衣柜”。

已在独立浏览器测试页检查三套服装的 36 种图集、试穿与保存、取消与重开、三次入口位置、吃饭途中换装、任务恢复，以及现有摸头、拖动、帽子、问候和减少动态效果。测试页不包含个人聊天记录。

## English

A small wardrobe with three complete outfits: classic maid, blue & white hoodie, and star pajamas. Preview a look before saving it. Rice feeding now completes three bites instead of stopping after one.

- All three outfits cover all 12 states, with 234 key poses in total.
- Open the wardrobe from the character menu, select a preview, and confirm with **Wear this outfit**. Cancel, Escape, or clicking outside restores the saved outfit. The selected card shows the current action in narrow windows.
- Meals repeat the twelve-pose scoop, spoon-to-mouth, and chewing cycle three times, for 36 pose visits over about 13 seconds before returning to the current task.
- Outfit changes preserve the elapsed time of the current action, along with the hat, position, size, and existing preferences. The selected outfit is remembered locally.
- Browser-driven playback, bounded decoded-atlas caching, pause, hidden-window behavior, and reduced-motion support are retained. No extra model calls are needed.

Download `DeepSeekGirl-Harness-v1.6.0.zip`, extract it, and add `DshDeepSeekGirl` in Harness. Existing users can back up and replace their plugin files, then quit and reopen Harness. Choose **Open wardrobe** from the character menu.

Checks in a standalone browser cover all 36 outfit/state atlases, preview/apply/cancel and saved reloads, three spoon-to-mouth visits, outfit changes during a meal, task restoration, and the existing interaction and greeting regressions. Previews contain no personal conversations.

New outfit artwork was generated with the built-in ImageGen tool using the existing character and poses as references. Selected source sheets, normalized frames, and prompts are included in the repository. This is an unofficial character plugin.
