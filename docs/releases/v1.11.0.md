# v1.11.0 · Pro 娘的冬日衣柜 / Pro winter wardrobe

## 给变身后的 Pro 娘，换上暖暖的冬装

成功选择 **DeepSeek Pro** 后，小鲸鱼仍会通过约 **2.2 秒**的水光、上升水波与淡入淡出效果变成成熟的鲸鱼娘。这一版会直接穿上你给 Pro 保存的衣服；切回 **Flash** 时，也会变回原来穿搭的小鲸鱼。**选择模型成功即可触发，不用发送消息，也不会为动画额外调用模型。**

Pro 的衣柜新增两套完整冬装，加上原来的鲸鱼女仆装，共有三套穿搭：

- **奶油蓝羽绒服**：长款奶油蓝绗缝羽绒服、蓝色针织围巾、深蓝裙摆与保暖短靴。
- **月牙绒绒斗篷**：深青色绒边斗篷、金色月牙扣、奶油色针织衫、星空刺绣长裙与短靴。

![Pro 的两套冬装](https://raw.githubusercontent.com/nailiang002-wq/deepseek-girl-harness/v1.11.0/docs/images/pro-winter.png)

### 怎么换衣服

切到 **Pro → 点击角色身体 → Pro 衣柜**，点选衣服试穿，再点 **就穿这套** 保存。取消、按 Esc 或点击衣柜外面会恢复已保存服装。Pro 和 Flash 各自记住穿搭，重新打开或再次变身后继续生效；Flash 的五套衣服继续保留。

![Pro 衣柜的实际插件测试页截图](https://raw.githubusercontent.com/nailiang002-wq/deepseek-girl-harness/v1.11.0/docs/images/pro-winter-wardrobe.png)

### 动画与互动

- 两套冬装均覆盖十二种状态，新增 **48 张独立完整人物姿势**。
- 待机和表情保持身体站稳，只让尾巴轻轻摆动；衣服与绒边留在固定身体层。
- 每套都有十二张完整吃饭动作帧，连续吃 **三口、约 13 秒**。抬手、入口、咀嚼、满足微笑均使用完整人物图，避免局部脸部或手臂贴片错位。
- 吃饭途中换装保留当前进度；正常大小、放大和戴铁盆帽均已检查。
- 冬装变身沿用水波与整个人物淡入淡出效果，使用保存的冬装姿势；摸头、鼓脸、拖动、问候和小账本继续保留。

### 下载与升级

下载本页附件 **DeepSeekGirl-Harness.zip**，解压后将整个 **DshDeepSeekGirl** 文件夹添加到 Harness 的第三方插件中。已有用户可覆盖原插件目录后重新载入，**不要只复制 `client.js`**。完整步骤见[中文说明](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.0/README.md#三步安装)。

已在 Windows 和 Harness 内置 SDK **0.2.1-rc.2** 环境验证。自动变身需要模型选择服务；缺少该服务的旧版 Harness 请先升级。暂停动画、减少动态效果或窗口隐藏时直接切换形态。Mac 仍待真机验证。

## A warm winter wardrobe for Pro

A successful **DeepSeek Pro** selection still triggers the approximately **2.2-second** water-and-light transformation. Pro now appears in her saved outfit; returning to **Flash** restores Little Whale's separate saved look. **No message or extra model call is required.**

Two complete winter looks join Pro's original whale-maid dress:

- **Cream & blue puffer:** a long quilted coat, knitted blue scarf, navy skirt hem and warm ankle boots.
- **Moonlit winter cape:** a teal fur-trimmed cape, gold crescent clasp, cream cable-knit sweater, star-embroidered skirt and ankle boots.

In Pro form, **click her body → Pro looks**, preview an outfit, then select **Wear this outfit**. Cancel, Escape or clicking outside restores the saved look. Pro and Flash remember their clothes independently across transformations and reloads; all five Flash outfits remain available.

### Animation and interaction

- Both winter outfits cover all twelve states, adding **48 complete character drawings**.
- Idle and expression poses keep the body steady while the tail sways. Coat and fur edges remain in the fixed body layer.
- Each outfit uses twelve whole-character feeding poses for **three bites over approximately 13 seconds**, without separately pasted face or arm overlays.
- Changing clothes during a meal keeps the elapsed progress. Normal size, enlarged size and the basin hat were checked.
- Winter transformations use the existing water effect and whole-character fades with the saved outfit. Head pats, pouting, dragging, greetings and the ledger remain available.

Images and GIFs show the real plugin in a standalone test page with no personal conversations or real account data. The source artwork and exact generation prompts are included in the repository.

### Install or upgrade

Download **DeepSeekGirl-Harness.zip** below, extract it and add the entire **DshDeepSeekGirl** folder as a third-party Harness plugin. To upgrade, replace the existing plugin folder's files and reload. Keep the entire folder. See the [English guide](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.0/README.en.md#install-in-three-steps).

Verified on Windows with Harness's bundled SDK **0.2.1-rc.2**. Automatic transformation requires the model-selection service; upgrade older Harness versions if necessary. Paused animation, reduced motion and hidden windows switch forms directly. Mac still needs native testing.
