## 中文

DeepSeek 娘是 DeepSeek Harness Desktop 窗口里的互动角色插件：跟随任务变表情，吃一盆白饭，捧空铁盆求饭，戴铁盆帽，并按时间跟你打招呼。

v1.3 包含 10 种状态、预加载透明图集、连续呼吸与轻晃、拖动与落地动作，以及保存位置和大小的功能。深夜会提醒注意身体；同一时段只自动问候一次。

下载附件 `DeepSeekGirl-Harness-v1.3.0.zip`，解压后在 Harness 的“插件 → 添加插件”中添加 `DshDeepSeekGirl` 文件夹。无需安装 Node.js，也无需构建。安装说明和图片演示见仓库 README。

已在 Windows 版 Harness Desktop 测试。角色的手势和表情仍由六个关键姿势组成，连续运动用于改善整体连贯性。

## English

DeepSeek Girl is an interactive character inside the DeepSeek Harness Desktop window. She reacts to tasks, enjoys plain white rice, asks for food with an empty iron basin, wears a basin hat, and greets you throughout the day.

Version 1.3 includes ten states, predecoded transparent sprite atlases, continuous breathing and swaying, pickup and landing motion, and saved position and size. Late-night greetings remind you to rest; automatic greetings appear once per time period.

Download `DeepSeekGirl-Harness-v1.3.0.zip`, extract it, and add the `DshDeepSeekGirl` folder through Harness’s Plugins → Add plugin. No Node.js or build step is required. See the repository README for installation details and image demos.

Tested on Harness Desktop for Windows. Expressions and hand gestures retain six key poses per state, combined with continuous motion.
