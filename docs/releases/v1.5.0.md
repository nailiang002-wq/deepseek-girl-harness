## 中文

这次先把两件事做细：开心吃白饭，以及摸摸头。

- 吃饭由六个姿势细化为十二个，依次舀饭、抬勺、送到嘴边、咀嚼、露出满足的微笑，约 4.4 秒后恢复当前任务状态。
- 轻点头部会眯眼轻蹭，并飘出小爱心。快速点头部三次，会短暂鼓脸；摸头和鼓脸各约 1.8 秒。
- 点击身体、右键或 Enter / 空格仍可打开菜单，菜单内也有“摸摸头”。
- 吃饭时忽略摸头；喂饭可接管摸头，拖动优先移动角色，取消指针操作不会误触摸头。保留位置、大小、帽子、问候和其他偏好。
- 新增状态仍使用预解码图集和浏览器动画。暂停、隐藏窗口和减少动态效果继续生效，不需要额外模型调用。

下载 `DeepSeekGirl-Harness-v1.5.0.zip`，解压后在 Harness 中添加 `DshDeepSeekGirl` 文件夹。已有用户先备份，再覆盖原插件目录并退出、重新打开 Harness。首次试用可以轻点头部，或从角色菜单选择“摸摸头”。

已验证：十二种图集、十二帧吃饭重播、轻点 / 连点 / 触屏、身体和键盘菜单、喂饭与拖动接管、帽子、问候、窗口边缘、减少动态效果与清理。独立测试页中，连续动画播放约三秒仍为零次角色组件刷新；这不代表所有机器都能达到固定帧率。

## English

Version 1.5 refines rice feeding and adds head-pat interactions.

- Meals now use twelve poses, from scooping rice and lifting the spoon to chewing and a satisfied smile; the current task returns after about 4.4 seconds.
- Tap her head for an affectionate nuzzle and little hearts. Three quick head taps trigger a playful pout. Both reactions last about 1.8 seconds.
- Body clicks, right-click, and Enter / Space open the menu, which also includes a head-pat action.
- Meals ignore head pats; feeding and dragging take priority over a pat. Saved preferences remain compatible.
- Predecoded atlases and browser playback are retained, including pause, hidden-window behavior, reduced motion, and local operation with no extra model calls.

Download `DeepSeekGirl-Harness-v1.5.0.zip`, extract it, and add `DshDeepSeekGirl` in Harness. Existing users can back up and replace their plugin files, then quit and reopen Harness.

Checked in a standalone browser: all twelve atlases, meal restart, head/body taps, rapid taps, touch input, keyboard menus, feeding/drag priority, hat preservation, greetings, reduced motion and cleanup. Continuous playback still caused zero character component renders over about three seconds; no fixed frame-rate guarantee is made.

New artwork was generated with the built-in ImageGen tool using the existing character as a reference. Selected source sheets, normalized frames, and generation prompts are included in the repository. Images and GIFs above are animation-asset previews.
