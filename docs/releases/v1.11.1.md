# v1.11.1 · 求饭间隔调整 / Rice request timing

自动求喂饭调整为 **每次随机等待 10～15 分钟**，让陪伴更安静一些。

- **首次与再次求饭**都使用新的间隔，每次自动捧盆约 6 秒。
- **喂饭后重新计时**，不会刚吃完就再次求饭。
- **忙碌、休息、打开菜单或隐藏窗口时延后**，恢复空闲、清醒和可见后再出现。
- **切换会话、重新打开时保留等待进度**，避免不断重置计时。
- 仍可点击白饭盆随时手动喂饭，或在 **更多 → 小设置** 中关闭自动求饭。

Flash 与 Pro 共用这项时间规则。Pro 冬装、双向变身和连续三口吃饭继续保留。

已检查首次等待、重复请求、喂饭重置、切换会话、忙碌 / 休息 / 隐藏延后，以及关闭功能后的计时器清理。发布的插件与本机测试通过的版本一致。

下载附件 **DeepSeekGirl-Harness.zip**，解压后保留整个 **DshDeepSeekGirl** 文件夹。升级可覆盖原插件目录后重新载入；不要只复制 `client.js`。[安装说明](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.1/README.md#三步安装)。

---

Automatic rice requests now wait a random **10–15 minutes** each time for a quieter companion.

- The first and subsequent requests use the same interval; each basin pose lasts about six seconds.
- Feeding starts a fresh wait.
- Busy, sleeping, open-menu and hidden-window states defer the request until she is idle, awake and visible.
- Conversation changes and reloads preserve the deadline.
- Manual feeding remains available. Automatic requests can be disabled under **More → Settings**.

The rule applies to both Flash and Pro. Pro winter outfits, bidirectional transformation and three-bite feeding remain available.

Checks cover initial and repeated requests, feeding resets, remounts, busy / sleep / visibility deferral, disabling and timer cleanup. The released plugin matches the approved local test build.

Download **DeepSeekGirl-Harness.zip** and keep the entire extracted **DshDeepSeekGirl** folder. To upgrade, replace the existing plugin folder's files and reload. [Installation guide](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.1/README.en.md#install-in-three-steps).
