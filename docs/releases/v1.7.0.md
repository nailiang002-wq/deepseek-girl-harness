## 中文

新增“饭钱小账本”：角色旁显示登录账户余额、今日预估费用和 Token 用量，点击查看明细，可从角色菜单隐藏。

- 余额复用 Harness 登录账户接口，包含充值和赠送余额，人民币与美元分开显示；本版不查询 API Key 或第三方账户余额。
- 今日 Token 按电脑本地日历日，从本机 Harness 会话记录汇总提供方上报用量。重试分别计入，最终样本不重复统计，分支继承历史去重，重新打开可恢复。
- 金额明确为**本机今日预估**：已知官方模型按峰谷费率给出人民币区间。价格核对日期为 2026-10-16；不代表账户实扣账单，不含其他设备、平台或未报告的用量。详情提供官方账单入口。
- 缺失用量、未知渠道或模型、无法确定的缓存字段会明确标注；未登录、查询失败和真实零值分别显示。
- 显示时约每分钟刷新，支持手动刷新；隐藏或关闭时停止轮询。余额只保存在内存，退出账户后清除。

下载 `DeepSeekGirl-Harness-v1.7.0.zip`，解压后在 Harness 添加 `DshDeepSeekGirl` 文件夹。已有用户先备份，再覆盖插件文件，退出并重新打开 Harness。衣柜、三口白饭、摸头、帽子和问候继续保留。

## English

Adds a small ledger beside the character with signed-in account balances, today's estimated fees, and Token usage. Click for details or hide it from the character menu.

- Native Harness account balances include recharge and bonus wallets, with CNY and USD kept separate. API-key and third-party balances are not queried by this release.
- Today's reported Tokens are derived from this local Harness profile's durable records, using the local calendar day. Retries count separately, final samples replace earlier samples, and inherited fork history is excluded.
- Monetary amounts are explicitly **local estimates**, using the off-peak-to-peak CNY rate range for known official models. Rates were checked on 2026-10-16. This is not the settled account bill and excludes other devices, platforms, and unreported usage. An official-bill link is provided.
- Missing evidence and unsupported routes/models are disclosed; sign-out, errors, and confirmed zero values are distinct.
- Refreshes about once a minute while visible, with manual refresh and no polling while hidden or disabled. Financial values stay in memory and old balances clear on sign-out.

Download `DeepSeekGirl-Harness-v1.7.0.zip`, extract it, and add `DshDeepSeekGirl` in Harness. Existing users can back up and replace the files, then quit and reopen Harness. Existing outfits and interactions remain available.

Checks cover day rollover, retries, final samples, fork deduplication, missing evidence, tariff coverage, read-only RPC, decimals/currencies, sign-out races, polling lifecycle, narrow windows, and existing animation regressions. Preview values are synthetic.
