# v1.10.0 · Flash ⇄ Pro 自动变身 / Automatic transformation

## 切到 Pro，让小鲸鱼变成鲸鱼女仆

在 Harness 当前会话中成功选择 **DeepSeek Pro**，就能看到约 **2.2 秒**的变身动画：浅蓝色光晕亮起，水环和水滴围绕角色向上展开；小鲸鱼逐渐淡出，蓝色长发、鲸鱼尾巴、白围裙与深蓝长裙的成熟鲸鱼女仆随水波登场。手写小提示会同步显示形态变化。

水光散去后，她继续陪你思考、回答和完成任务。**切回 Flash 也会播放变身动画**，小鲸鱼会穿回你之前保存的衣服。成功切换模型即可触发，**不用发送消息，也不会为动画额外调用模型**。

![Flash ⇄ Pro 变身与三口白饭演示](https://raw.githubusercontent.com/nailiang002-wq/deepseek-girl-harness/v1.10.0/docs/images/transformation.gif)

演示使用实际插件界面，模型选择与任务为独立测试页中的模拟数据。

### 本版还有这些变化

- **身体站稳、尾巴轻摆**：Pro 待机和表情采用固定身体与独立尾巴，取消整个人物左右摇摆。
- **修复吃白饭贴图错位**：使用统一对齐的完整人物动作帧，连续吃三口，约 13 秒后恢复任务状态；戴铁盆帽、放大和正常大小均已检查。
- **保留熟悉的互动**：摸头、鼓脸、拖动、铁盆帽、手写问候、转轮和摸头账本继续可用，Pro 头部点击与帽子位置适配新比例。
- **五套 Flash 服装保留**：切回 Flash 自动恢复已保存服装。Pro 当前只有专属女仆装；其衣柜可预选下次切回 Flash 的服装。
- **切换更稳妥**：快速选择以最后一次成功结果为准；吃饭、拖动或打开衣柜时会等待当前互动结束。启动应用和切换会话直接显示对应形态，避免重复播放。

![完整人物动作：连续吃三口白饭](https://raw.githubusercontent.com/nailiang002-wq/deepseek-girl-harness/v1.10.0/docs/images/feeding-pro.gif)

### 下载、安装与兼容性

下载本页附件 **DeepSeekGirl-Harness.zip**，解压后将整个 **DshDeepSeekGirl** 文件夹添加到 Harness 的第三方插件中。升级用户可覆盖原插件目录后重新载入；不要只复制 `client.js`。完整步骤见[中文说明](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.10.0/README.md#三步安装)。

已在 Windows 和 Harness 内置 SDK **0.2.1-rc.2** 环境验证。模型自动变身需要 Harness 提供模型选择服务，旧版若缺少该服务请先升级。当前识别官方 DeepSeek Pro 模型 ID，其他模型使用小鲸鱼形态。暂停动画、系统减少动态效果或窗口隐藏时直接切换形态。Mac 尚待真机验证。

## Switch to Pro and watch Little Whale transform

A successful **DeepSeek Pro** selection in the current Harness conversation triggers a **2.2-second** transformation. A pale blue glow appears, water rings and droplets rise around her, and Little Whale fades into a mature whale maid with long blue hair, a whale tail, a white apron, and a navy dress. A handwritten caption announces the change.

When the glow clears, she continues following your task. **Switching back to Flash plays the return transition** and restores her saved outfit. No message is required, and the animation makes no extra model calls. The opening GIF uses the real plugin in a standalone test page with synthetic model selections and tasks.

### Also in this release

- **Steady body, gentle tail:** Pro idle and expression states keep the body still and animate a separate tail layer.
- **Aligned feeding:** complete character drawings replace face/arm overlays. She eats three consecutive bites over approximately 13 seconds, then returns to the task state. Normal size, enlarged size, and the basin hat were checked.
- **Familiar interactions:** head pats, pouting, dragging, the basin hat, handwritten greetings, the action wheel, and the ledger remain available. Pro's head target and hat placement match her proportions.
- **Outfit memory:** all five Flash outfits remain. Pro currently has one dedicated dress; her wardrobe can preselect the next Flash outfit.
- **Considerate transitions:** rapid selections use the last successful result. Feeding, dragging, and wardrobe interactions finish first. Startup and conversation changes show the matching form directly.

### Install and compatibility

Download **DeepSeekGirl-Harness.zip** below, extract it, and add the whole **DshDeepSeekGirl** folder as a third-party Harness plugin. To upgrade, replace the files in the existing plugin folder and reload. Keep the entire folder. See the [English installation guide](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.10.0/README.en.md#install-in-three-steps).

Verified on Windows with Harness's bundled SDK **0.2.1-rc.2**. Automatic transformation requires the model-selection service; upgrade an older Harness version if it lacks that service. Official DeepSeek Pro model IDs select Pro; other models use Little Whale. Paused animation, system reduced motion, and hidden windows switch forms directly. Mac still needs native testing.
