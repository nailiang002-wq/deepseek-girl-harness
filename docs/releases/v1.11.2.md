# v1.11.2 · 修复鲸鱼娘显示不全 / Fix clipped mascot on DSH 0.2.2-rc.1

修复 DSH **0.2.2-rc.1** 中鲸鱼娘在有消息的会话里掉到窗口底部、只露出一半的问题。角色现在按整个窗口定位，缩小窗口时也能完整显示，并继续跟随当前会话的状态。

已在 Windows 上用同版本 DSH 复现并验证修复，同时检查了拖动、喂饭、衣柜和 Flash ↔ Pro 变身。

下载附件 **DeepSeekGirl-Harness.zip**。已有旧版的用户可以用解压后的文件覆盖原插件目录，再退出并重新打开 Harness。首次安装请参阅[安装说明](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.2/README.md#三步安装)。

---

Fixed an issue on DSH **0.2.2-rc.1** where Little Whale could slide to the bottom of the window and appear partly cut off in conversations with messages. She now stays within the window when the conversation layout changes or the window is resized, while still following the active conversation.

Reproduced and verified on Windows with the same DSH version. Regression checks covered dragging, feeding, the wardrobe, and Flash ↔ Pro transformation.

Download **DeepSeekGirl-Harness.zip**. To upgrade, extract the archive, replace the files in your existing plugin folder, then quit and reopen Harness. For a fresh install, see the [installation guide](https://github.com/nailiang002-wq/deepseek-girl-harness/blob/v1.11.2/README.en.md#install-in-three-steps).
